# 生命科学论文的"灵魂"与顶刊级判断标准

这份标准用来回答第三步的问题：**这篇文章有没有灵魂？它为什么是／不是一篇顶刊级别的文章？**

不要把它当作打分表机械填写。它的用途是让你在读完文章后，有一套共同的语汇去描述"这篇文章到底强在哪、弱在哪"，从而给出一个读者能拿去用的判断。打分只是结论的表达形式。

---

## 一、先定义"灵魂"

一篇文章的"灵魂"，是**它如果只能留下一句话，那句话是什么**。

判断灵魂的强弱，问三个问题：

1. **认知增量**：读完它，读者对这个领域的理解发生了什么改变？如果没有改变（只是"又找到一个例子"），灵魂就弱。
2. **不可替代性**：这句话能不能被同期其他文章轻易替代？如果换一篇同期论文，结论几乎一样，说明它不在关键路径上。
3. **可携带性**：这个结论能不能被带到别的体系里用？一个只在特定细胞系、特定条件下成立的机制，携带性差；一个能解释一类现象的规律，携带性强。

灵魂强的文章，读者会在写自己的 Introduction 或 Discussion 时引用它；灵魂弱的文章，读者只会在 Methods 里引用它的方法。

---

## 二、七个评估维度

### A. 概念创新（Conceptual advance）

- 本文提出的是**新概念／新范式**，还是给已有范式**加了一个新实例**？
- 它是否**推翻或修正**了领域内的既有认识？（"不是 X，而是 Y"这类转折）
- 把体系换掉（换基因、换细胞类型、换物种、换疾病）结论还成立吗？——可推广性。
- 如果结论是"某基因在某种癌症中高表达并促进增殖"，这属于填补空白，属于增量，不属于概念创新。

**顶刊信号**：一句话能让非本领域的科学家也觉得有意思。

### B. 因果链的完整性（Causality）

- 观察到的是**相关**还是**因果**？
- 有没有 **loss-of-function + rescue**？（机制类文章的黄金标准：敲低表型出现，回补后表型恢复）
- 有没有**上位／下位实验**（epistasis）把分子放进通路里的正确位置？
- **体外 → 体内**是否闭环？（细胞系 → 类器官 → 动物 → 人源样本）
- 有没有排除**旁效应**（off-target、载体效应、CRISPR 脱靶）？

**常见断裂点**：只有过表达没有敲除；只有敲除没有回补；只有体外没有体内；机制推论靠"已知文献"而不是本文实验。

### C. 证据的独立性与正交性（Evidence robustness）

- 核心结论有几条**互相独立**的证据线？（不同方法、不同模型、不同实验室来源的样本）
- 是否只依赖**单一组学平台／单一抗体／单一细胞系**？
- 有没有**正交验证**？例如 RNA-seq 的结果用 qPCR 或蛋白层面确认；单细胞的结果用空间或原位验证。
- 关键结论的 n 是多少？是生物学重复还是技术重复？（把技术重复当生物学重复检验是生命科学的常见统计错误——pseudoreplication）
- 多重检验是否校正？

**顶刊信号**：每条关键结论背后至少有两条不同技术路线指向同一结论。

### D. 方法学／资源贡献（Method & resource）

- 是否提供了**别人做不了的新技术、新平台、新资源**？（图谱、筛选文库、动物模型、算法）
- 这个资源会不会被领域**反复使用**？
- 对方法学文章，"灵魂"在于：**它让过去做不到的事变得可做**，或者**让过去做得慢的事变得快**。判断标准是它是否开辟了新的问题空间，而不只是把已有流程提速。
- 对资源／图谱类文章，"灵魂"在于：**它揭示了靠单个实验室无法看到的结构**（跨组织、跨疾病、跨物种的共性规律）。只做描述性罗列、不给可检验的新假设的图谱，灵魂较弱。

### E. 转化距离（Translation）

- 有没有**可操作的靶点／标志物／治疗策略**？
- 距离临床还有几层？（细胞系 → 类器官 → 小鼠 → 人源样本 → 临床试验）
- 转化潜力不必然是顶刊门槛，但如果文章的定位是"临床相关"，需要检查它兑现到什么程度。

### F. 严谨性与可重复性（Rigor）

- 统计检验是否匹配实验设计？样本量是否合理？
- 是否有**盲法、随机化、预注册**？（介入类研究尤其）
- **数据和代码是否公开**？原始数据是否可获取？
- 结论的措辞是否**超出**数据支持的范围（overclaim）？——这是审稿人最常攻击的点。

### G. 时机与竞争格局（Timing）

- 这个问题是不是**领域公认的难题**，还是作者自己造的问题？
- 为什么是**现在**、为什么是**这一组人**做出来的？
- 如果同期有 3 篇类似文章，它凭什么被记住？

## 三、判定标尺

给出结论时，用下面的标尺定位，并**明确指出落在哪一条、依据是哪些具体证据**。

| 判定 | 特征 |
|---|---|
| **顶刊级（CNS 主刊）** | A 维度提出领域级新概念（能改写教科书的一句话）；B、C 无短板；往往同时具备 D 或 E 中的一项突破。 |
| **领域顶刊级（Nature 子刊 / Cell Reports / PNAS / Genome Biology 等）** | B、C 扎实完整，A 中等（新机制但属于已有范式内的推进），或 D 提供高质量通用资源。这是绝大多数扎实工作的位置。 |
| **扎实但不够** | B 或 C 有明显缺口（缺 rescue、缺体内、单一线索），或 A 只是把已知结论换了个系统。 |
| **增量工作** | A 低 + B 有断裂：属于填补空白式研究，结论可预期。 |

**注意**：期刊等级 ≠ 文章质量。判定时要区分两种情况：
- 工作本身够顶刊但发在子刊 → 说明"它的灵魂足够，可能输在时机或完整性"。
- 工作本身不够但发在好刊 → 说明"它的包装／资源／团队弥补了灵魂的不足"。第二种情况对读者最有价值，因为它揭示了顶刊的隐形门槛。

---

## 四、输出时的要求

评估部分必须包含：

1. **灵魂一句话**：用一句话说清这篇文章的认知增量。
2. **分维度简评**：至少覆盖 A、B、C 三个维度，每个维度给出**具体证据**（哪张图、哪个实验），不能只给结论。
3. **明确判定**：它属于上面四档中的哪一档，以及**为什么**。
4. **如果是"不够顶刊"，缺什么**：指出最短的那块板，并说明补上它需要什么实验。
5. **如果够顶刊，强在哪**：指出哪一条证据或哪一个概念让它越过了门槛。

**禁止**：只写"该研究具有重要意义""为后续研究提供了新思路"这类空话。每一句评价都必须能指回文章中具体的图、实验或数据。
